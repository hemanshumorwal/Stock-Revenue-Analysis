# Analyzing Historical Stock and Revenue Data and Building a Dashboard

## Project Overview
This project focuses on extracting and analyzing historical stock price and quarterly revenue data for Tesla (TSLA) and GameStop (GME) using Python. The project was completed as part of the IBM Python Project for Data Science.

## Objectives
- Extract historical stock data using yfinance.
- Scrape quarterly revenue data using web scraping techniques.
- Process and analyze data using Pandas.
- Visualize stock prices and revenue trends using Matplotlib.

## Tools and Technologies
- Python
- yfinance
- Pandas
- BeautifulSoup
- Requests
- Matplotlib
- Jupyter Notebook

## Project Tasks
1. Extract Tesla historical stock data.
2. Scrape Tesla quarterly revenue data.
3. Extract GameStop historical stock data.
4. Scrape GameStop quarterly revenue data.
5. Visualize Tesla stock prices and revenue.
6. Visualize GameStop stock prices and revenue.

## Key Learnings
- Financial data extraction
- Web scraping
- Data cleaning and manipulation
- Data visualization
- Working with Python libraries
